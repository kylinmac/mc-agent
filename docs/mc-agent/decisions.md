## 4 后续 ADR 模板

下一个编号是 MC-ADR-0003，文件放 `docs/mc-agent/adr/mc-0003-<slug>.md`。`docs/adr/` 是上游 PI-Desktop 的 ADR，编号不共用，不往里加。只为长期约束写 ADR，普通交互调整直接更新对应文档。

```text
# MC-ADR-编号: 决定名称
状态：Proposed / Accepted / Superseded
日期：［待填写］
问题：具体需求、限制和受影响对象。
决定：选择什么，责任边界是什么。
备选与代价：没选什么，当前方案牺牲什么。
影响：需求、数据、权限、原型、测试和兼容性。
重访条件：什么变化发生时重新决定。
```
