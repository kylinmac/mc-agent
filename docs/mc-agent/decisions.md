## 2 决策清单

标“已定”的已有结论；其余是技术细节，在对应阶段编码前定。

| 编号 | 问题 | 建议 | 冻结时点 |
|---|---|---|---|
| D1 | 首版新增范围 | 已定：首版 R1–R4（+R5），第二阶段 R6–R9 | 2026-10-14 |
| D2 | 项目协作方式 | 已定：单机多项目，不做团队共享 | 2026-10-14 |
| D3 | 模型／登录承诺 | 保留 Pi 全覆盖目标，按锁定版本建立实际验证矩阵 | 基线验收 |
| D4 | 资料格式 | Markdown／文本用于上下文，其他格式登记与打开，URL 不自动抓取 | 原型确认 |
| D5 | 完成规则 | 已定：Agent 完成后待验收，用户确认才完成；验收条件必填，可由 AI 起草 | 2026-10-14 |
| D6 | 会话关联 | 每次任务执行新建 Desktop 会话，同任务可有多次执行 | 数据设计 |
| D7 | 项目身份 | 已定：项目组 ID，工作区平等，资料目录占 `roots[0]`（R1）；剩 legacy 转存储型项目组的迁移细节 | 数据设计 |
| D8 | 存储及迁移 | 既有 Rust 数据层增量保存，文件仍是正文来源 | 数据设计 |
| D9 | 上下文限额 | 必需资料先核验，超限明确处理，保留有限依据快照 | 数据设计 |
