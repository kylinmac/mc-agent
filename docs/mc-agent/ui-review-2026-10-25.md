## 建议改进（未改，需要定方向）

### P1：影响整体观感或理解

1. **标题栏标签过多且太短。** 会话和页面（设置、创作、定时）混在同一排，每个只剩 4 个字左右，最右侧被截断，也没有溢出入口。建议：页面不进标签栏（或固定在左侧图标区）；标签设最小宽度，放不下时出现「更多」下拉；关闭未固定的旧标签。
2. **设置页内容铺满整个窗口宽度。** 宽屏下标签在最左、开关在最右，相隔上千像素；扩展和定时页面都是居中限宽，风格不一致。建议设置内容最大宽度约 760px 并居中。
3. **设置项说明藏在「?」里。** 输入建议（会多发请求）、网络宽松模式、无尽重试这类有代价或有风险的选项，说明应直接显示在标题下方，「?」只留给次要解释。
4. **设置的保存方式不统一。** 系统提示词页需要点「保存 / 放弃修改」，其他页面改完即生效。建议统一：要么全部即时生效（系统提示词也逐项保存），要么在有未保存修改时固定显示底部操作栏。
5. **「AI → 默认项」分组过杂。** 权限模式、Shell、链接打开位置、思考展示、上下文读数、回车发送、输入建议、平滑流式、粘贴阈值放在一起。建议拆成「智能体行为」「对话显示」「输入框」三组。
6. **扩展市场按钮层级过重。** 每张卡片一个高对比实心「安装」按钮，加上顶部同样实心的「刷新插件市场」，整页都是主按钮。建议卡片改次要按钮（悬停或选中时强调），刷新改图标按钮。权限标签大面积橙色，低风险权限也像警告，建议只有高风险用醒目色。

### P2：用词和一致性

7. **字号档位名「中杯 / 大杯 / 超大杯 / 超超大杯」。** 有趣但不够专业，也不直观，旁边还有同义的滑块。建议用「小 / 标准 / 大 / 特大」，或只保留滑块和百分比。
8. **「新建任务」一词多义。** 未命名会话叫「新建任务」，定时任务侧边栏的入口也叫「新建任务」，页面按钮又叫「创建任务」。建议未命名会话叫「新对话」，定时页统一用「新建定时任务」。
9. **创建项目对话框里有「对话」选项。** 点它会离开对话框去开一个普通对话，在「创建项目」里属于意外跳转。建议移出，由侧边栏的「新建临时对话」负责。同一处「简单项目 / 普通项目」标题和副标题重复，副标题可写成「只关联文件夹」。
10. **内置模板名称和说明是英文**（blank、software、「Empty resource folder.」、architecture 等目录说明）。建议内置模板按界面语言显示名称和说明；目录名可保留英文，但说明要本地化。
11. **侧边栏标题前的标签像标题的一部分。** 「资料 打开计算器…」「Pi purge-analyze…」里的起始目录和来源标签与标题同色同字号。建议改成小号胶囊或次要颜色。
12. **信息栏显示为 0 的行。** 「MCP 工具 0、AGENTS.md 0、项目记忆 0」占满行数，建议为 0 时折叠到「其他」或隐藏。
13. **关于页显示「host 0.20.1」。** 安装版的应用版本是 mc-agent 1.0.x，下面的 host 却是上游的版本号，容易误读。建议放进诊断信息，或改称「内核版本」。

### P3：细节

14. 设置页打开时搜索框自动获得焦点并显示高亮描边，第一眼最显眼的是搜索框而不是内容。建议只在按 ⌘F 或点击时聚焦。
15. 模型页「目录：不可用 · 0 个模型 · 更新于 从未获取」读起来不通，建议「模型目录尚未获取」加一个获取按钮。
16. 创作页左侧对话栏较窄，工具行和长回复折行多；建议允许拖宽，或默认更宽一点。

## 其他检查

- PR #17（Grok 会话导入等）：路径限定、符号链接拒绝、大小上限、渲染进程不能指定文件路径，安全上没有问题；29 项导入测试通过。扫描时会完整读取每个 Grok 会话来计数，会话很多时首次扫描较慢，可改成只读元数据。
- 语音输入（PR #12/#13/#15）：音频格式严格校验、仅 HTTPS、拒绝重定向、不回传服务商错误内容、订阅令牌只发往官方地址、锁屏/休眠/关窗取消，设计合理。OpenAI 类服务商未填 Base URL 时没有默认地址，会请求失败。
- 全部测试通过：host-core 1021、mc-computer 25、agent-runtime 1399、shared 1282、host-runtime 122、desktop 4088（8 个取消为已知的超时/WebSocket 用例），typecheck 和 lint 通过。
