## 流程

| 阶段 | 行为 |
| --- | --- |
| 开始 | 跟随界面语言生成初始提示词；中文语言用中文，其余用英文。复用 Plan 模式 |
| 了解 | 只读查看列出的目录与说明；不写资料、不建分类、不登记索引 |
| 讨论 | 围绕项目目标、资料范围、分类与处理方式提出建议，只询问尚不明确的事项 |
| 确认 | 用 SubmitPlan 提交逐文件清单、目标分类、登记／移动／起草动作、预计数量、排除范围与验证方式；等待用户明确批准 |
| 执行 | 复用已有批准计划的 Agent 执行路径；只处理批准清单，范围扩大需再次确认 |

计划审核本身由现有 host 写入 `.pi/plan`，不属于整理产物；不新增审批协议或执行器。Plan 模式沿用已有工具限制，Bash 仍受既有权限策略与只读指令约束，并非新增文件系统沙箱。

## 默认整理规则

- 优先本项目自有需求、设计、决策和分析记录；上游手册、教程、贡献指南不批量收录，确有需要时建议少量入口。
- 同内容多语言资料优先当前对话语言，避免重复登记。
- 分类是建议，用户可调整或留空；不再为了填满分类自动起草。起草须列入批准清单并标明 AI 来源与未确认项。
- 工作区只登记、不复制、不改原文；移动仅限资料目录。现有控制文件与文件覆盖保护保留。
- 资料目录内的文件已自动列出，不再登记到 INDEX.md。
