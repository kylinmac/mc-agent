# Windows 整体回归与问题清单（2026-10-22）

范围：桌面测试集、Windows 安装／更新、顶栏平台隔离、Computer Use helper。对应现有 R15／P10／V50、R11.12／P11／V51，未新增产品需求。没有操作已安装的 mc-agent、PI-Desktop 或调用付费模型。

## 问题表

| 编号 | 类型 | 问题与证据 | 处理 |
| --- | --- | --- | --- |
| W01 | 产品缺陷 | 更新安装器抛异常或发送 error 后，`isInstallingUpdate()` 仍为 true；两个新增失败用例均复现，可能影响后续退出确认 | 清除标记、关闭退出时自动重试、记录错误状态；回归通过 |
| W02 | 校验缺陷 | 安装目录 `C:\.` 和含 `..` 的根目录等价路径通过原校验；只校验不安装的原生测试复现 | 先按完整路径判断是否为根目录，再用规范化后的路径安装；10 个路径用例通过 |
| W03 | 测试缺陷 | 4 个模型测试文件用 URL.pathname 作为文件路径，Windows 下读不到内置目录；插件迁移测试还重复转换 URL | 改用 fileURLToPath 或直接传 URL；相关测试通过 |
| W04 | 测试缺陷 | Windows 品牌断言仍要求 PI-Desktop，与已确认的 mc-agent 安装身份冲突 | 更新断言为 mc-agent；通过 |
| W05 | 测试缺陷 | 日志、缓存路径断言固定使用 `/`；终端断言在 Windows 仍要求 Unix 登录 shell | 路径断言使用本机路径规则；Windows 另测 COMSPEC 及无登录参数；通过 |
| W06 | 验证环境不足 | Electron 可执行文件和 renderer 构建产物缺失，桌面点击流程无法启动 | 未将这些失败当作产品缺陷；完整桌面 E2E 待补运行环境 |
| W07 | 平台测试限制 | macOS 签名、远端 SSH／POSIX shell 和 Unix 权限断言在本机 Windows 失败 | 未修改 macOS 行为、未降低权限校验；需在适用平台验证 |
| W08 | 待核查兼容性 | 插件访问未登记目录返回 INVALID_ARGUMENT，而测试要求 NOT_FOUND；操作仍被拒绝 | 保持安全拒绝，尚未更改错误码契约 |

- 更新：自动／手动模式、便携版边界、下载进度、Windows 静默安装参数、macOS 原参数均有回归。

- 安装器测试入口只存在于 INSTALLER_TEST 构建；生产构建也已成功编译。
