## 工程范围

- shared：可选提问元数据、配置与跨进程类型。
- agent-runtime：内部定时、取消清理、明确的工具结果。
- agent-host：超时关闭待答状态，避免重新进入等待输入。
- desktop / host-runtime：启动配置传递、设置页面、历史卡与补选。
- 权限审批仍走现有 host-core 路径，本功能不调用自动批准。

参考 [OpenAI 异步工具说明](https://developers.openai.com/api/docs/guides/async-tool-calling)：异步交互状态由应用管理。这里复用本项目运行时与消息队列，不声称复刻 Codex 未公开实现。

## 限制

可选性来自模型声明，无法保证模型永远正确分类；默认关闭，并保留独立工具权限门禁。应用退出终止当前等待，不会在重新启动时把旧提问自动当作授权执行。
