# 创作工作台方案（生图，后续生视频）

**状态：** 一期已实现，见 [MC-ADR-0013](adr/mc-0013-creative-studio.md)
**日期：** 2026-10-20

## 目标

模型生图是另一类工作：主要空间给素材和成果，对话只占一小块。需要：

- 素材管理：参考图、生成结果、收藏，按项目归类，文件可在 Finder 里直接看到。
- 成果对比：同一提示词换模型、换参数后并排比较，选出满意的。
- 生成过程可追踪：等待、生成、失败、取消都看得到，不丢结果。

## 已确认

| 问题 | 决定 |
|---|---|
| 入口 | 左侧竖栏一个“创作”图标 |
| 模型 | 用 pi 模型配置里具备生图能力的模型（现有“生图模型”设置）。对话模型不需要自己会生图：任何对话模型（包括 Grok）都可以调用设置里的生图模型 |
| 代码绘制 | 模型写代码画出的图（像素图、图标、图表等）同样算图片素材 |
| 范围 | 先把图片做好；画布提前到二期；视频暂不做 |
| 本地模型 | 暂不接（ComfyUI 等） |

## 入口与项目

- 左侧竖栏一个“创作”图标，打开创作工作台。
- **创作是项目的用途，不是另一套项目。** 复用现有项目组的 ID、目录和权限（MC-ADR-0003），只加一个用途标记（`code` / `creative`），决定默认从哪个入口打开、主侧栏是否列出。
  - 创作用途的项目默认只出现在“创作”里，不混进主侧栏的代码项目列表。
  - 普通项目也能“在创作中打开”，素材库同样可用。
  - 素材是项目文件夹（默认工作区）里 `creative/` 下的真实文件，代码会话可以按路径直接引用（例如把生成的图标放进前端项目）。选资料目录时同样是 `<资料目录>/creative/`，没有别的规则。
  - **更改存储位置只影响之后的新文件**，已保存的文件和记录留在原处。选过的位置不再属于项目、或目录离线时会报错并要求重新选择，不会悄悄换到别的目录（R13.1，2026-10-22）。
  - 新建创作时可以选一个**创作目录模板**，只在空的 `creative/` 下建立模板里的分类文件夹（R13.2）。
  - 存储在资料目录时，`creative/` 下的生成文件不进项目资料清单；用户确认过的文件除外（R3.2）。

## 界面布局

```
┌──┬──────────────┬────────────────┬──────────────────────────────────────┐
│竖│ 搜索素材     │ [直出] 对话    │ 全部            已选 2 · 对比 · 移动到│
│栏│              │ 生图模型 ▾     │                                      │
│  │ 创作项目     │ 提示词…        │ 樱花背景，柔和光 · grok · 4张         │
│创│ ▸ 春季海报   │ 张数 4 存到 ▾  │ ▣ □ ▣ □                              │
│作│              │ 参考图 [+添加] │                                      │
│  │ 全部 · 收藏  │ 1 [图] 参考 ▾  │ 代码绘制 · 1张                        │
│  │ 对比集       │ 2 [图] 风格 ▾  │ □                                    │
│  │ 分类      +  │ [生成]         │                                      │
│  │  未分类      │                ├──────────────────────────────────────┤
│  │  ▾ 角色      │                │ 队列：生成中 1 · 等待 2 · 失败 1（重试）│
│  │     角色A    │                │                                      │
└──┴──────────────┴────────────────┴──────────────────────────────────────┘
```

- **侧栏：** 创作项目列表、存放位置；当前项目下是“全部 / 收藏 / 对比集”和分类树。分类由用户自建、可多级（`角色/角色A`、`背景/乡村/山野`），每个分类就是 `creative/` 下的一个文件夹，没分类的在“未分类”。树上可新建子分类、双击或 F2 重命名、右键删除（内容移到上一级）；把网格里的图片（多选时一起）拖到分类上即移动文件。沿用设置页、扩展页、定时任务页的侧栏模式。
- **左侧面板：** 两种模式。
  - **直出：** 选生图模型、写提示词、选张数和“存到”的分类（默认是当前正在看的分类，否则未分类）。参考图点“添加参考图”从素材库挑选（可按分类筛选），按顺序发送，每张选用途。只显示所选模型支持的参数。
  - **对话：** 工作台里的精简对话，不跳到主页。Agent 可以写代码画图，也可以调用生图模型；会话的系统提示告诉它分类列表和存放规则，结果直接进素材库。可在主界面打开完整对话，也可新开一个。
- **右侧（主空间）：**
  - **网格：** 按“一次生成任务”分组，组头写提示词、模型、张数、时间、状态；失败的结果占位显示原因。代码绘制和模型结果放在一起，只用来源标记区分。
  - **多选：** 对比、用作参考、移动到分类、移出素材库、删除文件。多选和参考图是分开的：只有“用作参考”才加入参考图。
  - **对比：** 选 2–4 个并排，缩放和平移同步；两张图可用滑块叠加比较。可存成“对比集”，附备注和选定的那一个。
  - **画布：** 二期。
- **详情：** 大图预览 + 生成快照（提示词、模型、实际参数、参考素材）+ 来源关系。操作：再生成、变体、用作参考、加入对比、收藏、导出、从素材库移除、删除文件。
- **参考图的用途：** 参考（借鉴内容和元素）、修改这张（在这张图上改）、风格参考（只借画风、配色、笔触，不借内容）。用途按顺序写进发给模型的提示词。
- **底部队列：** 一期就有：等待、生成中、保存中、完成、失败、已取消；可取消、可对失败项重试。

## 关键设计

### 1. 生成任务从一期开始

图片也会耗时、部分失败、被取消。每次生成都是一条**生成任务**记录：

- 状态：`等待 → 生成中 → 保存中 → 完成`，或 `失败`、`已取消`；一个任务可部分成功（4 张成 3 张）。
- 每个结果单独记录状态、文件路径和对应的素材 ID。
- 应用重启后，未完成的任务标为中断，不会一直显示“生成中”（与项目任务的处理一致）。
- 以后接视频时，在同一模型上扩展“提交 / 轮询”状态，不另起一套。

### 2. 表单和 Agent 走同一条生成路径

现有生图工具在 Electron Main 里执行（`services/image-generation-service.ts`），负责鉴权、读写参考图、落盘。两个入口都调用它：

- Agent 的 `image_generation` 工具调用 → 创建生成任务 → 执行 → 登记素材。
- 参数表单提交 → 创建同一种生成任务 → 同一条执行与登记流程。

鉴权、权限、费用提示、落盘目录、素材登记只有一份实现，聊天生成和表单生成的记录完全一致。

### 3. 文件归属与删除

- **导入的图片复制进项目**，放进当前分类的文件夹，原文件改动或删除不影响项目；同一文件按内容哈希去重。
- **生成结果和代码绘制**写进所选分类的文件夹（`creative/<分类>/`，没选则 `creative/未分类/`）；代码绘制的脚本存在 `creative/scripts/`。
- **“从素材库移除”和“删除文件”分开：** 移除只去掉库里的记录，文件留在磁盘；删除文件需要单独确认。
- **先落盘、再登记，登记可补：** 任务记录先保存结果文件路径，再登记素材。登记失败（或应用中途退出）时，按任务记录补登记，不会再调用模型。启动时也会扫描“已落盘未登记”的结果。

### 4. 选中素材的固定

不让 Agent 根据实时选区去猜“第三张”：

- 发送消息时，把附带的素材固定为**素材 ID + 顺序 + 用途**（参考图 / 要修改的图 / 风格参考），随消息保存，输入框和消息里都显示缩略图。
- 之后切换项目、改变选择，都不影响已发送的请求。
- Agent 通过素材 ID 读取文件；给 Agent 的“列出 / 读取素材”工具也以 ID 为准。

### 5. 参数按模型能力显示

- 每个生图模型带一份能力描述：支持的尺寸或比例、张数上限、参考图数量上限、是否支持编辑、是否支持种子、质量档位等。
- 表单只显示支持的参数；不支持的参数不发送，也不静默忽略：Agent 提出不支持的参数时，明确告诉用户。
- “再生成”表示**复用同一配置再跑一次**，界面不承诺结果一致（多数服务没有可复现的种子）。

### 6. 两种生成方式：模型生成与代码绘制

素材有四种来源：**参考**（复制进来的）、**模型生成**、**代码绘制**、**导入**（已有文件登记进库）。

代码绘制是对话模型写程序（例如 Python + Pillow）画图、运行、查看结果再调整，适合像素图、图标、图表、简单矢量图：结果可精确复现、可逐像素修改，不消耗生图额度；不适合照片级写实图。

- **登记：** 给 Agent 一个“保存为素材”工具：传入图片路径、所用脚本和运行命令。创作会话的系统提示要求代码画出的成品通过它登记。对话里显示的任何图片也可以手动“加入素材库”。
- **快照：** 保存脚本内容（复制一份，按哈希去重）、运行命令和解释器、所在会话；与模型生成的快照（提示词、模型、参数）并列，在详情里按来源显示。
- **再生成：** 在项目里重新运行保存的脚本，走 Agent 现有的命令执行权限，不在后台静默执行；同一脚本结果一致，改脚本即得新版本，新旧版本可以直接对比。
- **任务记录：** 代码绘制同样记为生成任务（入口为“代码”），队列和素材登记与模型生成共用。

### 7. 对比保存引用和快照

- 一次生成有多个结果，每个结果是独立素材，有自己的 ID。
- 每个生成结果保存**生成快照**：当时的提示词、模型、实际发送的参数、参考素材列表（含顺序和用途）。之后改了设置或删了参考图，快照仍可读。
- 对比集保存的是素材 ID 的引用、顺序、备注和选定项，不复制文件。
- 来源关系是**多对多**：一个结果可以用了多张参考图，一张图也可以被多次引用，按“用途”区分，不只记单个父图。

## 数据（host-core SQLite）

| 表 | 内容 |
|---|---|
| 素材 | ID、项目、来源（参考 / 模型生成 / 代码绘制 / 导入）、文件路径、内容哈希、尺寸、缩略图、收藏、来自哪个任务结果 |
| 生成任务 | ID、项目、入口（对话 / 表单 / 代码）、会话 ID、模型或脚本、生成快照、状态、时间、错误 |
| 任务结果 | 任务 ID、序号、状态、文件路径、素材 ID、错误 |
| 素材引用 | 结果素材 → 被引用素材、顺序、用途（多对多） |
| 对比集 | ID、项目、标题、备注、选定素材；成员：素材 ID 与顺序 |

文件在项目文件夹的 `creative/` 里，数据库只存索引和元数据；数据库丢失时可按目录和任务快照重建。表结构版本记在 `mc_schema_versions`（键 `creative`），逐步迁移，不改上游的 `user_version`。跨进程的类型与方法表在 `packages/shared/src/types/creative.ts`。

## 分期

1. **一期（图片）：**
   - “创作”入口、项目用途标记、创作项目列表。
   - 生成任务与队列、统一生成路径（对话 + 参数表单）、素材登记与补登记。
   - 素材库（网格、详情、移除与删除）、参考素材复制入项目。
   - 选中素材固定为附件、按能力显示参数。
   - 代码绘制登记为素材（“保存为素材”工具、对话图片手动加入）、脚本快照与重新运行。
   - 对比视图与对比集。
2. **二期：** 画布（自由摆放、标注、圈选局部重绘）、批量矩阵生成（提示词 × 模型 → 对比网格）、评分与选片导出。
3. **以后：** 视频生成（在生成任务上扩展提交与轮询）、本地模型。
