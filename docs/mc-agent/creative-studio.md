# 创作工作台方案（生图、生视频）

**状态：** 方案草稿，待确认后再动手
**日期：** 2026-10-20

## 目标

模型生图、生视频是另一类工作：主要空间给素材和成果，对话只占一小块。需要：

- 素材管理：参考图、生成结果、收藏，按项目归类，文件可在 Finder 里直接看到。
- 成果对比：同一提示词换模型、换参数后并排比较，选出满意的。
- 视频任务是异步的、耗时几分钟，需要队列和进度。

## 开源项目参考

| 项目 | 值得借鉴 | 对我们 |
|---|---|---|
| [Jaaz](https://github.com/11cafe/jaaz)（Lovart 的开源替代） | 无限画布 + Agent 对话：草图、标注、让 Agent 生成；云端 API 与本地 ComfyUI 都支持 | 最接近“对话占小部分、素材占主空间”。画布放到后期；视频能力有资料说仍在规划，需看仓库确认 |
| [InvokeAI](https://cdn.jsdelivr.net/gh/invoke-ai/InvokeAI@main/README.md) | Boards 分组素材、画廊、图片可拖到任意输入当参考、图片自带提示词和参数可一键召回 | 素材库与元数据设计的蓝本 |
| [ComfyUI 资产面板](https://docs.comfy.org/interface/assets) | 左侧“Media Assets”入口，搜索、预览、复用、删除成果；队列与历史单独一块 | 侧栏与生成队列的蓝本 |
| [Open Generative AI](https://github.com/anil-matcha/open-generative-ai) | 图片和视频合在一个工作室；第三方介绍称可在同一会话里切换模型并排对比 | “同提示词多模型对比”的来源 |
| [Cherry Studio](https://docs.cherry-ai.com/en-us/~gitbook/pdf) / [LobeHub](https://lobehub.com/changelog/page/1) | 聊天客户端都给生图单独开了页面 | 说明“和对话分开的独立页面”可行，但它们没有素材管理和对比 |

共同点：主空间是画廊或画布，对话是侧边面板或输入框，素材带完整的生成记录（提示词、模型、参数、父图）。

## 入口：左侧竖栏一个“创作”图标

建议只加一个“创作”图标，图片、视频在里面按类型筛选，不分两个图标：

- 图片会变成视频（图生视频），视频帧也会变回图片；素材、对比和队列需要共用。
- 竖栏按“做哪类工作”分更合适，图片和视频是同一类工作的两种产出。

仍以**项目**为单位：新增“创作项目”，复用现有的项目组 + 资料目录（MC-ADR-0003）。文件放在真实目录（`~/.mc-agent/projects/<名称>/assets`、`generations/<日期>/`），可在 Finder 打开，也方便交给其他工具。创作项目只出现在“创作”里，不混进主侧栏的代码项目列表。

## 界面布局

```
┌──┬──────────────┬───────────────────────────────────┬────────────┐
│竖│ 搜索素材     │ [网格] 对比  画布        已选 2 · 对比 │ [对话] 参数 │
│栏│              │                                   │            │
│  │ 创作项目     │ 樱花背景，柔和光 · gpt-image · 4张 │ 把选中的两张│
│创│ ▸ 春季海报   │ ▣ □ ▣ □                           │ 换成横版…  │
│作│   产品宣传片 │                                   │            │
│  │              │ 同提示词 · seedream · 2张          │            │
│  │ 春季海报     │ □ ▶                               │            │
│  │  全部成果    │                                   │ 选中 2 项已 │
│  │  参考素材    │                                   │ 作为上下文  │
│  │  收藏        ├───────────────────────────────────┴────────────┤
│  │  对比集      │ 队列：视频 1/2 生成中 62% · 图片完成 4  预估 ¥3.2 │
└──┴──────────────┴────────────────────────────────────────────────┘
```

- **左侧栏：** 创作项目列表；当前项目下分“全部成果 / 参考素材 / 收藏 / 对比集”，加图片/视频筛选。沿用设置页、扩展页、定时任务页的侧栏模式。
- **中间（主空间），三种视图：**
  - **网格：** 按“一次生成”分组，组头写提示词、模型、张数、时间，同一提示词不同模型的结果一眼看出来。
  - **对比：** 选 2–4 个并排，缩放和平移同步；两张图还可用滑块叠加比较；视频同步播放。对比结果可存成“对比集”，附备注和选定的那一个。
  - **画布：** 后期，类似 Jaaz：自由摆放、标注、圈选局部重绘。
- **详情：** 点开素材，大图预览 + 元数据（提示词、模型、参数、种子、参考图、费用），以及父子版本的“血缘”。操作：再生成、变体、用作参考、图生视频、加入对比、收藏、导出。
- **右侧窄面板（可收起），两种模式：**
  - **对话：** 和 Agent 说话；中间选中的素材自动成为对话上下文，可以直接说“把这两张改成横版”。
  - **参数：** 不想聊天时直接填表：提示词、模型、尺寸、张数、参考图（从左侧拖进来）。
- **底部队列：** 视频要几分钟，必须有队列：进度、失败重试、费用预估。

## 技术思路（在现有基础上加）

- **已有：** 图片生成工具（`packages/agent-runtime/src/image-generation`）、设置里的生图模型绑定、OpenAI Images 适配。
- **素材库：**
  - **存储：** host-core SQLite 新增素材、生成任务、对比集、血缘关系四类数据；缩略图缓存。
  - **登记：** 工具生成的图自动登记到当前创作项目的素材库。
- **视频：**
  - **生成：** 新增 `video_generation` 工具，提交异步任务，轮询取回结果。
  - **Agent 访问：** Agent 可以等待任务或稍后再查；另给 Agent 列出、读取素材的工具，它才能理解“第三张”。
- **模型：** 先接几家，候选：Seedream / Seedance（火山）、可灵、海螺、通义万相、Veo、Gemini 生图，以及 fal.ai / Replicate 这类聚合平台。本地 ComfyUI 可后期再接。

## 分期

1. **一期：** “创作”页、创作项目、图片素材库、网格、详情、对比视图、侧边对话。复用现有生图工具，单独可上线。
2. **二期：** 视频生成、队列、图生视频、视频同步对比。
3. **三期：** 画布、批量矩阵生成（提示词 × 模型 → 对比网格）、评分和选片导出。
