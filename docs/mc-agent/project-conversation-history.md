# 同项目对话回查（R5.1；P7；V71）

2026-11-03 用户确认：已有项目转为模板项目时，整理会话需要读取其他对话，提炼已讨论的需求、设计和验证结果。

| 项目 | 契约 |
| --- | --- |
| 工具 | ProjectHistory；list 按标题查找同项目对话，read 按会话 ID 读取或按关键词回查正文 |
| 可用模式 | Agent、Plan、Goal；不依赖压缩；通过 ToolSearch 可发现；子代理不继承 |
| 范围 | 当前会话项目组内的本机对话，包括资料目录和多个工作区；无项目、远程项目、跨项目、已删除对话拒绝 |
| 身份 | Runtime 固定调用者 sessionId；sidecar 验证已启动会话；host-core 根据数据库校验项目归属，不信任模型提供的路径 |
| 分页 | 列表最多 20 条；正文复用有界历史读取，最多 50 条、每条 4000 字符、总输出约 24KB，返回扫描范围、截断和续查位置 |
| 内容 | 返回用户／助手文本、角色、时间和消息 ID；不返回思考、工具参数／结果、附件正文、子代理内部消息 |
| 并发 | 读取 JSONL 不持有状态锁，返回前再次验证调用者与目标仍属于原项目 |
| 使用 | 先找相关对话，按需读取；总结时注明来源，区分用户明确确认、助手建议与实际测试记录；旧批准不授权新操作，不把密码带入整理文档 |

本工具只读，不改现有 ContextHistory、会话记录、权限模式或整理确认流程。不会自动读取所有项目、全量灌入历史或写资料。
