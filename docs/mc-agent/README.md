## 这次最需要你确认

1. 首版是否包含项目任务，还是先做项目概览与资料管理？
2. 是否接受“Agent 执行 → 用户验收 → 完成”？
3. 三个核心场景是否符合实际；选择真实项目作为样例。
4. 是否需要团队共享；当前建议先做单机多项目。

目标用户、macOS 首发、Fork 与接受开源已经确定，不需要重填。

## 状态约定

- 已确定：用户确认的方向或当前 Accepted ADR。
- 源码确认：存在实现路径，尚不等于运行验证通过。
- 建议／待评审：本轮提出的需求与设计，未冻结。
- 未验证：尚未构建、运行、登录或执行测试。

需求 R、页面 P、验收 V 编号互相对应。方案更新时同步需求、原型、数据与验收；避免把上游已有能力重新列为待开发。
