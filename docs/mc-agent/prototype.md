# mc-agent 项目工作台原型

状态：低保真评审草案，不是可运行页面。继承 PI-Desktop 现有会话、设置、审批和 Work Panel；下面只画新增项目管理入口。对应[需求文档](requirements.md) R9–R15。

## 1 信息结构

| 页面 | 内容 | 需求 |
|---|---|---|
| P1 项目概览 | 目标、待办、阻塞、待验收、近期会话 | R9 |
| P2 项目资料 | 文档／资源目录、类别、确认状态、变更提示 | R10 R11 R15 |
| P3 项目任务 | 目标、验收条件、引用资料、执行历史 | R12 |
| P4 启动预览 | 本次项目、执行目录、模型、资料及版本 | R13 |
| P5 任务验收 | 执行结果、产物、验证说明、通过或退回 | R14 |
| 继承界面 | 原对话、工具、审批、设置、停止与排队 | R1–R8 |

项目入口使用已有项目组。点击项目后进入概览还是保留原会话导航，待评审；不静默改变原导航行为。

## 2 主工作台

```text
┌──────────────┬────────────────────────────────────────────┐
│ 项目列表     │ 项目 A    概览 | 资料 | 任务 | 会话           │
│ · 项目 A     ├────────────────────────────────────────────┤
│ · 项目 B     │ 项目目标：［可编辑摘要］                    │
│              │ 待办 3   进行中 1   待验收 2   阻塞 1      │
│ 原有会话入口 │                                            │
│              │ 需要处理                                   │
│              │ · 需求文档已变化              ［核对］     │
│              │ · 登录功能开发完成            ［验收］     │
│              │                                            │
│              │ 最近任务                       ［新建任务］│
│ 设置／扩展   │ 任务名称      状态       关联会话            │
└──────────────┴────────────────────────────────────────────┘
```

数字来自任务状态，不根据模型措辞猜测进度。项目概览不取代正在运行的会话。

## 3 资料目录

```text
项目资料                              ［登记文件］［添加链接］
名称           类型       状态              关联任务
需求.md        需求       已确认            登录功能
架构.md        架构       确认后有修改       登录功能
原型.html      原型       草稿              —
参考链接       参考       未保存本地快照     —

选中资料：打开原文件 | 查看关联 | 确认当前版本 | 解除关联
```

确认是一项明确用户操作。打开、登记、确认与允许 Agent 执行是不同动作。文件缺失显示修复路径；解除关联提示“不删除原文件”。

## 4 任务与启动预览

任务详情：标题 → 目标 → 验收条件 → 引用资料 → 执行历史 → ［开始执行］。

点击开始后显示：
- 项目与实际执行目录（包括是否为 worktree）。
- 模型与原有权限模式。
- 必需／可选资料，确认状态、实际读取版本、未选入的条目。
- ［返回修改］与［确认并启动］。

必需资料缺失、确认后变化或超限时显示原因与修复入口，不能在角落提示后照常执行。URL 不声称已经读取正文。

## 5 结果与验收

```text
任务：登录功能                    状态：待验收
本次依据：需求.md 的确认版本［查看］
执行会话：［打开］
产物：［相关文件］
验证：［实际测试或人工检查记录］
尚未完成：［剩余问题／无］

［退回待办并填写原因］                 ［确认验收通过］
```

Agent 自述与真实验证分开展示。无结果证据时不自动通过。文件已被删除时保留原记录并显示缺失。

## 6 评审走查

| 情况 | 界面必须表达 |
|---|---|
| 空项目 | 登记已有资料或创建任务的入口 |
| 文件外部修改 | 确认版本已变化，哪些任务受影响 |
| 工作目录切换 | 当前任务仍属于原项目，不跟着界面选择变化 |
| 停止／失败 | 继承上游状态，任务阻塞，保留已产生结果 |
| 启动过程中崩溃 | 启动状态待核实，不重复发起 |
| 重启应用 | 任务、资料和执行关联恢复 |
| 用户不接受结果 | 记录原因并退回，保留本次历史 |

待你确认：项目默认入口、资料分类、任务是否必须先填验收条件，以及是否接受人工验收闭环。
