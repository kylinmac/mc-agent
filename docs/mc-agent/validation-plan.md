# mc-agent 验收与开发计划

状态：开发阶段，R1–R11 已合入 `main`，逐项状态见 2.1 节。采用 Fork 后先验证继承能力，再验证项目管理增量；不再从自建内核和协议开始。

## 1 基础能力回归

| 编号 | 需求 | 场景 | 通过标准 |
|---|---|---|---|
| V1 | B1 | 模型 API、OAuth 登录／刷新／退出、错误凭据 | 所列组合按实际结果标通过或受限；凭据不泄漏 |
| V2 | B2 | 流式与连续两轮对话 | 内容无重复，上下文和终态正确 |

| V4 | B4 | 各权限模式、Plan／Goal 允许与拒绝 | 不能绕过授权，不串会话 |

先用仓库内的两个最小样例，见 `examples/fixtures/mc-agent/`（仓库根目录下）。它们不是 git 仓库；需要 git 的用例（worktree、分支）先复制到临时目录再 `git init`。

| 场景 | 样例 | 核验方式 |
