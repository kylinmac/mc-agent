## 3 样例项目

先用仓库内的两个最小样例，见 `examples/fixtures/mc-agent/`（仓库根目录下）。它们不是 git 仓库；需要 git 的用例（worktree、分支）先复制到临时目录再 `git init`。

| 场景 | 样例 | 核验方式 |
|---|---|---|
| S1 整理资料 | `single-project/`：文档散在 `docs/` 和 `docs/notes/` | 建项目后用 R5 整理进模板分类，从概览找到需求和设计 |
| S2 文档驱动开发 | `split-project/`：`web/` 与 `server/` 两个平等工作区，各有 AGENTS.md | 从资料目录统筹，Worker 分别派到 web 和 server；各自加载对应 AGENTS.md |
| S3 跨项目继续 | 同时打开两个样例，修改其中一份资料 | 切换、重启后各自恢复，无串用，资料变化有提示 |

真实项目验证留到发布准备（M5）。记录基线提交、模型、初始文件和允许操作，以及成功情况、耗时、调用数与人工介入。
