# MC-ADR-0026：Agent 访问工作面板

日期：2026-11-05。状态：已确定。R27；P8。

## 背景

用户要求 Agent 能读取和操作右侧各类面板。PTY 终端原来只向界面提供输出，模型无法读取用户看到的报错。各工具缺少统一面板定位。

## 决定

新增 WorkPanelList、WorkPanelRead、WorkPanelAction。全部先经过 host-core 工具权限检查，再由 Main 操作持有的资源。List／Read 为只读，Action 为高风险且不允许 Plan；远程会话不映射本机目标。

Renderer 仅返回按会话分组的标签元数据或终端画面，不能直接执行模型指定的任意 IPC。Main 核验调用会话及终端所有权，终端输入保留原始输入的审批预览。浏览器操作指定会话和标签。

交互式 shell 可能已有未提交的输入，无法仅凭本次文本判断完整命令。自动模式也需逐次审批带 termId 的终端动作（聚焦除外），避免绕过现有 Bash 自动模式保护；普通命令可继续使用 Bash。

插件页共享实例只允许操作当前显示归属会话。读取无障碍树，动作限定为点击、正常文本输入及常用按键；不执行模型提供的 JavaScript，不绕过插件文件路径、保存和冲突检查。每次动作绑定读取快照；页面隐藏、换会话或实例换代后失效。虚拟化编辑器的屏外文本可能不在树中，结果明确说明；完整磁盘内容使用现有文件工具。

画布、后台任务、Git 变更和协作沿用已有专用工具；统一入口提供数据与定位。所有返回内容都是不可信数据，不是提示词或授权。

## 影响

增加了 Agent 对用户交互终端及插件 UI 的操作边界，因此写入不能沿用无审批的 Renderer IPC。SQLite 所有权、插件进程权限和现有文件工具保持原样，不改数据库。请求有超时和取消，退出终端保留有界输出，关闭标签和应用时清理。

实现与验证见[工作面板访问](../work-panel-agent-access.md)。
