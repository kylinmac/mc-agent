# MC-ADR-0013: 创作工作台（一期：图片）

**Status:** Accepted
**Date:** 2026-10-20
**Deciders:** 产品负责人

## 背景

方案见 [创作工作台方案](../creative-studio.md)。生图需要独立空间管理素材、对比成果，对话只占一小块；模型写代码画出的图也算素材，但要和模型生成的图分开。

## 决定

1. **入口与项目。** 左侧竖栏一个“创作”图标。创作项目就是普通项目加用途标记（`kv` 命名空间 `mc.projectPurpose`，不改上游的项目记录），一定落在某个真实文件夹上，新建时三选一：
   - 选择文件夹：用它新建一个项目，作为工作区（文件夹已属于某个项目时提示改用那个项目）；
   - 已有项目 + 新文件夹：把文件夹加入项目作为工作区；
   - 已有项目 + 已有工作区。
   标记为创作项目不移动任何文件；创作项目仍出现在主侧栏的项目列表里。
2. **存储（每个项目可选，默认工作区）。** 文件存在项目某个文件夹（默认第一个工作区，也可选资料目录）下的 `creative/` 里，选择记录在 `kv` 命名空间 `mc.creativeStorage`。
   - 布局：每个分类一个子文件夹（`角色/角色A/`），没分类的放 `未分类/`，代码绘制的脚本放 `scripts/`。生成结果、导入的图片、代码绘制都按分类存放，不再分“参考 / 生成”目录。
   - 放在工作区时会进代码仓库，是否加入 `.gitignore` 由用户决定。
   - 改存放位置只影响之后的文件，已保存的留在原处；从创作发起的对话也在该文件夹里运行。
3. **数据。** host-core 自有表 `mc_creative_*`（素材（含所属分类）、生成任务、任务结果、素材引用、分类、对比集、对比成员），缺失时创建，不改上游 schema 版本。参考图复制进项目（按内容去重）；结果和删除都限定在项目的文件夹内。
4. **一条生成路径。** Electron main 的 `creative/creative-generation.ts` 统一处理：先建任务，再生成；每张结果先落盘写入任务记录，再登记为素材；登记失败按记录补登记，不会重新调用模型。表单（`creativeGenerate`）和 Agent 的 `GenerateImages` 工具（会话属于创作项目时）都走这里；其他会话仍走原来的 scratch 流程。应用启动后、第一个任务开始前，把上次未结束的任务标为“已中断”。
5. **代码绘制。** 新增 Agent 工具 `SaveCreativeAsset`（低风险，host-core 只做授权）：只接受项目文件夹或会话 scratch 里的图片和脚本，登记为“代码绘制”，快照保存命令和脚本副本。图片归入工具参数里的分类（默认未分类）：在项目里的移动过去，项目外的复制过去。代码绘制和模型结果放在一起，只用来源标记区分。
6. **界面。**
   - 侧栏：创作项目、存放位置，以及全部、对比集和分类树（不设“收藏”：素材已按项目和分类组织）。分类可多级（`背景/乡村/山野`），在树上新建子分类、双击或 F2 重命名、右键删除（内容移到上一级）；把图片拖到分类上即移动文件。
   - 左侧面板，两种模式：
     - **直出：** 选生图模型（与设置里的候选相同，默认全局设置，按项目记住；只对工作台生效）、写提示词、选张数和“存到”的分类（默认是当前正在看的分类，否则未分类）。参考图通过“添加参考图”从素材库挑选，按顺序发送，每张可选用途。
     - **对话：** 工作台里内嵌一个精简对话（不跳到主页），在项目文件夹里运行；Agent 可以写代码画图，也可以调用生图模型，会话的系统提示告诉它分类和存放规则。对话可在主界面打开完整版，也可新开。
   - 右侧：成果网格，按天连排（今天 / 昨天 / 日期），同一批次挨着，提示词和来源悬停显示，生成中和失败的占位也在网格里；详情页有生成快照、引用关系和操作。
   - 对比集就是对比工作区：上方对比区，布局可选横排、竖排、网格（列数自动或 2–6），最多 12 张，缩放平移同步；滑块模式在对比区里任选两张叠加，图片拖到左 / 右半边即放到那一侧；下方是本项目图片条（可按分类筛选），往上拖到末尾细长的“添加”位添加、拖到某张上替换，对比区内互拖交换位置；已保存的对比从下拉框打开；切到其他视图时当前对比保留。左侧直出 / 对话面板始终保留，在对比集里发消息会附带对比区图片的顺序和路径。
   - 网格操作按常见相册 / 文件管理器习惯：单击选中，⌘ 单击增减、⇧ 单击连选，在空白处拖动框选、单击空白清除；双击、空格或回车打开预览，预览里 ← → 切换；悬停显示勾选圈和提示词 / 来源，图块上不放删除按钮。右键菜单：打开、在访达中显示、拷贝图片、用作参考、对比、移动到…、移出素材库、删除文件…；空白处右键：导入图片、全选、显示文件夹。键盘：⌘A 全选、Esc 清除、方向键移动、Delete 移出素材库（可撤销）、⌘Delete 删除文件（需确认）。
   - 选择与参考分开：网格里的多选只用于对比、用作参考、移动到分类、移出素材库、删除文件；“用作参考”才会加入参考图。
   - 用途写进提示词：参考（借鉴内容和元素）、修改这张（在原图上改）、风格参考（只借画风、配色、笔触，不借内容），按顺序逐条附在提示词后，模型据此区分。
   - 导入图片和拖入文件进当前分类；底部是生成队列，可取消、可重试。
   - 删除语义：“从素材库移除”只隐藏记录，“删除文件”需要确认。
7. **Grok 订阅生图。** xAI 订阅账号提供 `grok-imagine-image-2.0` / `-quality` / `grok-imagine-image`，用聊天同一个 OAuth token 调 `api.x.ai/v1/images/*`（JSON，`b64_json`，编辑时单图用 `image`、多图用 `images`）。已实测：订阅账号可以生图。
8. **订阅账号的生图模型列表。** xAI 账号的列表从账号读取（`/v1/image-generation-models`，读不到时用 `/v1/models` 里的 image 模型；已实测账号返回三个模型），内置列表只在读不到时兜底；ChatGPT（Codex）没有列出生图模型的接口，仍用内置列表。用户可在 设置 → 模型 给订阅账号手动添加模型 ID（`kv` 命名空间 `mc.accountImageModels`），与账号列表合并。

9. **分类就是文件夹。** 分类名按路径记录（`/` 分级，最多 6 级，`未分类` 和 `scripts` 保留）；重命名和移动都同时改磁盘和记录，删除分类把其中的图片和子分类移到上一级并删掉空文件夹。

## 影响

- 改动上游：
  - `oauth.ts`：`accountImageModels`；`ipc/provider-ipc.ts`：provider 列表带上账号生图模型；`ImageGenerationModelRow.tsx`：单一服务商时菜单只显示模型名；`ModelConfigPage.tsx`：挂上手动添加区。
  - `permissions.rs` 和 `tools/mod.rs`：新增 `SaveCreativeAsset`。
  - `rpc/mod.rs`：分发 `creative.*`。
  - `packages/shared/src/image-generation.ts`：xAI 账号生图模型。
  - `packages/agent-runtime`：xAI 传输方式、工具声明。
  - 桌面端：竖栏、页面标签、路由、`image-generation-service.ts`（拆出 `resolveImageBinding`）、`sidecar.ts`、`session-launch.ts`（创作会话的系统提示）、`register.ts`、`mc-split-view.ts`（`pinSessionPane`，让内嵌对话在后台持续接收）、`sidebar-footer` 测试。
- 新增：`mc_creative.rs`、`rpc/mc_creative_rpc.rs`、`electron/main/creative/*`、`electron/main/ipc/mc-creative-ipc.ts`、`src/features/creative/*`。

## 暂未做（后续）

- 代码绘制的“重新运行”按钮；对话中任意图片“加入素材库”。
- 二期：画布、批量矩阵生成、评分与选片导出。
