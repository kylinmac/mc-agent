# MC-ADR-0031 AI 创建定时任务时确认运行权限

已确定，2026-11-21。对应 [R44](../requirements.md) 和 [V44](../validation-plan.md)。

定时任务可以在当前对话结束后多次运行。用户需要在创建时决定今后每次运行采用的审批模式。

- 本地对话调用 `ScheduledTaskCreate` 时，host-core 在已有的工具审批流程中挂起调用。会话的全自动模式和历史工具授权都不能代替本次确认。禁止该工具的会话模式仍直接拒绝。
- 桌面端展示任务参数、模型选择及权限选择；模型默认跟随应用设置，可为此任务固定服务商、模型和推理等级，默认每次询问。审批结果按请求 ID 与本次调用绑定。宿主从确认结果读取权限，模型传入的工具参数不能设置该字段。
- 已有客户端仍可确认或拒绝创建。确认时未指定运行权限，宿主保存“每次询问”。非交互调用需要审批时返回 `APPROVAL_REQUIRED`。
- 任务保存权限配置，首次运行时创建会话；复用会话时应用当前任务配置。手动创建沿用编辑表单。
